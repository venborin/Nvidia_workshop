Projecting onto excited determinants

The CC energy is E = ⟨Φ₀|Ĥ̄|Φ₀⟩. The amplitudes t are determined by projecting the similarity-transformed Schrödinger equation onto all excited determinants ⟨Φμ|:

⟨Φμ| Ĥ̄ |Φ₀⟩ = 0   for all μ ≠ 0

These are the amplitude equations. They are nonlinear because Ĥ̄ contains products of T̂ with itself. For CCSD (singles and doubles), we project onto singly and doubly excited determinants:

⟨Φia| Ĥ̄ |Φ₀⟩ = 0     ⟨Φijab| Ĥ̄ |Φ₀⟩ = 0

The similarity-transformed Hamiltonian Ĥ̄

Using the BCH expansion and normal-ordering with respect to |Φ₀⟩ (Wick's theorem), Ĥ̄ can be written as a sum of zero-, one-, two-, three-, and four-body operators. For CCSD, only the zero-, one-, and two-body parts contribute to the projected equations (three- and four-body parts give zero when contracted with singles/doubles projectors).

The key intermediates (using spin-orbital notation, indices i,j,k... occupied; a,b,c... virtual):

  • Fock matrix: fpq = hpq + ∑i ⟨pi||qi⟩
  • Dressed one-body operator: F̃pq = fpq + ∑ie tie ⟨pe||qi⟩ + ½ ∑iemn timen ⟨pe||mn⟩ + …
  • Dressed two-body operator: W̃pqrs = ⟨pq||rs⟩ + ∑e ter ⟨pq||es⟩ + … (includes T₂ contributions)

These intermediates absorb the infinite series of contractions from e−T̂ĤeT̂ into effective one- and two-body operators that can be evaluated efficiently.

CCSD amplitude equations (spin-orbital form)

0 = fai + ∑e fae tie − ∑m fmi tma + ∑me ⟨am||ei⟩ tme + ½ ∑mnef ⟨mn||ef⟩ timef + …

0 = ⟨ab||ij⟩ + P(ij)P(ab) [ ∑e ⟨ab||ej⟩ tie − ∑m ⟨mb||ij⟩ tma ] + ½ ∑ef ⟨ab||ef⟩ tijef + ½ ∑mn ⟨mn||ij⟩ tmnab + ∑me ⟨mb||ej⟩ timae + …

Where P(ij) and P(ab) are antisymmetrizers. These are solved iteratively (e.g., DIIS-accelerated fixed-point iteration).

CCSD(T): Perturbative triples

Full CCSDT scales as O(N⁸) and is prohibitively expensive. CCSD(T) adds a non-iterative perturbative correction for connected triples:

ΔE(T) = ¹/₃₆ ∑ijkabc (tijkabc)* ⟨Φijkabc| Ĥ̄ |Φ₀⟩C

where the triples amplitudes are approximated from the CCSD amplitudes via first-order perturbation theory:

tijkabc ≈ ⟨Φijkabc| Ĥ̄ |Φ₀⟩C / (εi + εj + εk − εa − εb − εc)

This gives near-CCSDT accuracy at O(N⁷) cost, making it the "gold standard" for single-reference systems.
